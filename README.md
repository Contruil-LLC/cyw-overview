## Framework Overview

CYW applies network infrastructure principles — VLAN segmentation, OSI-layer mapping, and routing protocols — to AI orchestration, attention management, and reasoning audit.

The framework spans several layers and components:

- **Multi-Model Pipeline Architecture** — role-specialized routing across multiple AI models with novel sequencing properties (subject of provisional patent USPTO 63/980,310, filed February 11, 2026)
- **Canary Protocol** — integrity verification framework using hash-chained evidence ledgers and cryptographic attestation to detect AI fabrication, drift, and tampering
- **Virgil OS** — NIST-aligned observability infrastructure with SHA-256 audit, automated integrity auditing, and sovereign monitoring frameworks
- **Layer 0 Sovereign Survival** — narrative game application of CYW principles to Zero Trust architecture and human decision-making
- **ServicePath** — operational tooling for service hour tracking with immutable audit logs

Each component has its own repository under the Contruil-LLC organization. Most are private during the active patent prosecution window.
